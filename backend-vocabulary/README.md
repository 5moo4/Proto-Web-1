# 백엔드단어장

프론트엔드단어장(`../ui-vocabulary/`)과 구분되는 독립 페이지입니다. `index.html`을 브라우저에서 열면 실행됩니다. 외부 요청이나 설치가 필요 없습니다.

10개 개념: API, Authentication, Authorization, Database, Cache, Validation, Job Queue, Rate Limiting, Transaction, Load Balancing.

각 카드는 상황 조작 → 단계별 처리 경로 → 결과 → 한글·영문 이름과 한 줄 설명으로 구성됩니다. 모든 데이터는 브라우저 메모리의 학습용 상태이며 새로고침하면 사라집니다. 실제 인증·데이터베이스·송금·서버 기능을 제공하지 않습니다.

단순화한 규칙: 캐시는 수동으로 비우며, 요청 제한 시간은 ‘다음 1분으로’ 버튼으로 진행합니다. 작업 큐는 작업자 한 명이 수동 실행하고 최대 6개를 대기시킵니다. 로드 밸런서는 Round Robin 방식으로 배분합니다. 실제 서비스의 모든 구현 방식을 대표하지 않습니다.

프론트엔드 페이지와 상단 링크로 왕복할 수 있습니다. 단계별 상태를 읽을 수 있도록 각 단계는 약 2초 동안 표시합니다. 동작 줄이기 설정에서도 읽기 시간은 유지합니다.
