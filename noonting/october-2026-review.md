# 서울캘린더 2026년 10월 검토 기록

검토일: 2026-10-02. 대상: `seoulcalendar.html`의 14개 기관·분류, 94개 일정.

## 세 차례 검토

1. 기관별 공식 전시·행사 목록과 10월 달력 데이터를 대조했다. 전년도 행사, 다른 지역 전시, 9월에 종료된 행사가 섞였는지 확인했다. 9월부터 이어지는 전시는 실제 시작일을 보존했다.
2. 행사 상세·포스터와 목록의 날짜를 다시 대조하고, 웹 열람 및 실제 브라우저에서 링크 목적지를 확인했다. 코엑스 19개와 aT센터 13개 상세 페이지는 각각 실제 브라우저로 열었다. 서울시 축제 상세 페이지, 국립중앙박물관 및 서울시립미술관 상세 페이지도 확인했다. 웹 수집 도구에서 실패했던 전쟁기념관·세종문화회관·DDP·날씨 링크는 실제 브라우저로 확인했다.
3. 수정된 HTML의 실제 스크립트를 오프라인 DOM 모형에서 실행했다. 시작·종료일 188개, 31일 배치, 모든 행사 버튼의 상세 날짜·기관·링크, 네 종류 필터와 전체 보기, 한국시간 날짜 경계 및 모바일 상세 이동 분기를 검사했다. 요일은 JavaScript UTC 계산, 별도의 그레고리력 계산, 한국시간 Intl 계산 세 방식으로 비교했다.

각 URL에 대해 세 번씩 접속했다는 뜻은 아니다. 공식 자료 대조 → 상세·목적지 대조 → 구현 회귀검사의 서로 다른 세 검토다.

## 범위와 한계

달력의 연속 표시는 **공식 전시·행사 기간**이지 매일 개관 보장이 아니다. 서울시립미술관의 10/12·19·26(월) 휴관과 10/5 정상 개관, 전쟁기념관의 월요일 휴관 규칙 및 10/6(화) 휴관은 상세 설명에 반영했다. 기타 기관의 휴관·프로그램별 시간은 공식 안내를 확인하도록 표시한다. [시립미술관 안내](https://sema.seoul.go.kr/kr/whatson/exhibition/detail?exNo=1509709), [전쟁기념관 10월 안내](https://www.warmemo.or.kr/Home/H40000/H40200/H40201/boardView?board_key=5443)

외부 링크의 확인은 검토 시점 기준이다. 향후 서버 장애·일정 변경까지 보장하지 않는다. 일반 일정 링크는 접속 가능하더라도 특정 행사를 자동 선택하지 않으며, 기관 화면에서 해당 전시를 골라야 한다.

로컬 HTML의 실제 브라우저 시각 검사는 이번 검토에서 수행하지 못했다. 오프라인 DOM 검사는 실제 화면 배치·글꼴·스크롤을 검증하는 브라우저 테스트의 대체물이 아니다.
