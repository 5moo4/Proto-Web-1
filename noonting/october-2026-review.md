# 서울캘린더 2026년 10월 검토 기록

검토일: 2026-10-02. 대상: `seoulcalendar.html`의 14개 기관·분류, 94개 일정.

## 세 차례 검토

1. 기관별 공식 전시·행사 목록과 10월 달력 데이터를 대조했다. 전년도 행사, 다른 지역 전시, 9월에 종료된 행사가 섞였는지 확인했다. 9월부터 이어지는 전시는 실제 시작일을 보존했다.
2. 행사 상세·포스터와 목록의 날짜를 다시 대조하고, 웹 열람 및 실제 브라우저에서 링크 목적지를 확인했다. 코엑스 19개와 aT센터 13개 상세 페이지는 각각 실제 브라우저로 열었다. 서울시 축제 상세 페이지, 국립중앙박물관 및 서울시립미술관 상세 페이지도 확인했다. 웹 수집 도구에서 실패했던 전쟁기념관·세종문화회관·DDP·날씨 링크는 실제 브라우저로 확인했다.
3. 수정된 HTML의 실제 스크립트를 오프라인 DOM 모형에서 실행했다. 시작·종료일 188개, 31일 배치, 모든 행사 버튼의 상세 날짜·기관·링크, 네 종류 필터와 전체 보기, 한국시간 날짜 경계 및 모바일 상세 이동 분기를 검사했다. 요일은 JavaScript UTC 계산, 별도의 그레고리력 계산, 한국시간 Intl 계산 세 방식으로 비교했다.

각 URL에 대해 세 번씩 접속했다는 뜻은 아니다. 공식 자료 대조 → 상세·목적지 대조 → 구현 회귀검사의 서로 다른 세 검토다.

## 범위와 한계

달력의 연속 표시는 **공식 전시·행사 기간**이지 매일 개관 보장이 아니다. 서울시립미술관의 10/12·19·26(월) 휴관과 10/5 정상 개관, 전쟁기념관의 월요일 휴관 규칙 및 10/6(화) 휴관은 상세 설명에 반영했다. 기타 기관의 휴관·프로그램별 시간은 공식 안내를 확인하도록 표시한다. [시립미술관 안내](https://sema.seoul.go.kr/kr/whatson/exhibition/detail?exNo=1509709), [전쟁기념관 10월 안내](https://www.warmemo.or.kr/Home/H40000/H40200/H40201/boardView?board_key=5443)

외부 링크의 확인은 검토 시점 기준이다. 향후 서버 장애·일정 변경까지 보장하지 않는다. 일반 일정 링크는 접속 가능하더라도 특정 행사를 자동 선택하지 않으며, 기관 화면에서 해당 전시를 골라야 한다.

로컬 HTML의 실제 브라우저 시각 검사는 이번 검토에서 수행하지 못했다. 오프라인 DOM 검사는 실제 화면 배치·글꼴·스크롤을 검증하는 브라우저 테스트의 대체물이 아니다.

## 2026-10-03 추가 재검토

> 후속 수정 완료: 아래 확인 보류 및 대비 문제는 문서 마지막의 ‘업로드용 최종 수정’ 기록을 함께 참고한다.

소비자가 실제 방문일을 정할 때 중요하게 보는 날짜를 먼저 확인하고, 링크 목적지와 색상 분류·가독성을 이어서 점검했다. 대상은 같은 94개 일정과 `seoulcalendar.html`이다. 이번 재검토는 기록만 추가했으며 HTML은 변경하지 않았다.

### 날짜 및 공식 자료 대조

- 기존 오프라인 회귀검사를 다시 실행했다. 94개 일정의 시작·종료일 188개, 요일, 달력상 31일 배치, 반복 버튼 965개의 일정 연결, 필터 네 종류 검사가 통과했다.
- 세텍 4개, 코엑스 마곡 7개, aT센터 13개 일정의 공식 달력 또는 상세 페이지를 브라우저에서 대조했다. aT센터의 13개 상세 주소 모두 열렸고, 각 행사 날짜가 달력 데이터와 일치했다.
- DDP 5개 일정은 공식 전시 목록의 기간과 일치했다.
- 세종문화회관 4개 일정은 공식 2026년 10월 전시 목록과 날짜·요일을 대조해 일치함을 확인했다.
- 국립중앙박물관의 추사·기증유물·대나무 전시, 국립현대미술관 서울관 및 덕수궁관 전시는 공식 상세/목록 기간과 대조했다. 이전 항목들의 입력 기간은 일치했다.
- 서울시 축제의 21개 고유 상세 주소를 확인했다. 정동야행은 공식 행사기간 10/29(목)~31(토), 미리 정동야행 10/29(목), 본 행사 10/30(금)~31(토)로 표기되어 있다.
- 강남페스티벌은 서울 축제 상세에 적힌 10/3~5와 별도 공식 강남페스티벌 사이트의 10/3(토)~5(월)가 일치한다. 서울 축제 상세의 포스터 문구 일부는 본문과 다르지만 날짜 범위는 3~5일로 일치한다.
- **비어페스트 코엑스 2026은 원문 내부 날짜 불일치로 확인 보류.** 달력 데이터와 코엑스 상세 페이지 상단 기간은 10/7(수)~10/10(토)이지만, 같은 페이지의 관람시간에 10/11(일) 운영시간도 표시된다. 상세 페이지 하나만으로 마지막 운영일을 확정할 수 없어 달력을 그대로 두었다. [코엑스 비어페스트 상세](https://www.coex.co.kr/exhibitions/비어페스트-코엑스-2026/)

### 링크

- 행사별 69개 고유 주소를 검토했다. aT센터·DDP·전쟁기념관·코엑스 비어페스트 등 자동 웹 조회에서 내용을 얻지 못한 주소도 실제 브라우저로 확인해 페이지가 열리는지 확인했다.
- 상단 기관 일정 링크, 날씨, 한강 행사, 구별 축제 링크도 열림을 확인했다. 서울시립미술관 상단 링크는 방문 안내 페이지로 연결된다.
- 접속 불가 링크는 발견하지 못했다. 기관 전체 일정 목록은 특정 행사를 자동 선택하지 않으므로, 개별 상세 페이지가 있는 행사는 그 상세 링크를 사용한다.

### 색상 분류 및 대비

- 달력에 쓰이는 14개 기관·축제 색상과 상단 범례의 색상값이 서로 일치한다. 행사 분류와 다른 색으로 표시된 항목은 확인되지 않았다.
- 글자 대비 계산에서 세텍 행사 버튼은 약 **3.24:1**, 코엑스 행사 버튼은 약 **4.46:1**이다. 일반 크기 글자에 대한 WCAG AA의 4.5:1 기준에 미달한다. 세텍은 대비가 특히 낮다.
- 국립중앙박물관 행사 선택 뒤 오른쪽 상세 카드의 어두운 초록 글자와 파란 배경은 약 **2.01:1**로 계산되어 가독성 개선이 필요하다.
- 비교 기준: [W3C WCAG 대비 최소 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

### 검토 범위

- 휴관일 미표시 규칙, 정동야행과 축제 선택 분류, 서울시립미술관 상단 링크는 기존 사용자 결정대로 유지했다.
- 날짜·링크 검토와 오프라인 코드 검증은 완료했지만, 로컬 HTML 화면의 실제 시각적 브라우저 검증은 하지 않았다. 링크의 접속 여부와 일정 자체의 향후 변경은 별개이므로 게시 직전 공식 일정을 다시 확인하는 편이 안전하다.

## 업로드용 최종 수정

- 사용자 결정에 따라 비어페스트 코엑스 종료일을 **2026-10-11(일)**로 반영했다. 행사기간은 10/7(수)~10/11(일)이며 11일 달력 칸에도 표시된다. 공식 원문의 상단 기간과 관람시간 불일치는 앞선 기록대로이며, 이번 변경 근거는 사용자의 명시적 결정이다.
- 코엑스 버튼 글자색을 `#111827`로 조정해 대비를 4.71:1로 개선했다.
- 세텍 버튼 글자색을 흰색으로 조정해 대비를 5.18:1로 개선했다.
- 국립중앙박물관 상세 카드 배경을 `#dbeafe`로 조정해 설명문 대비를 6.91:1로 개선했다. 기관별 달력 버튼과 범례의 분류 색상은 일치한다.
- 수정 후 기존 검증 스크립트 통과: 94개 일정, 시작·종료일 188개, 31일 배치, 행사 버튼 966개의 상세정보 및 링크 연결, 필터 동작. 비어페스트 종료일에 대한 회귀 검사도 추가했다.
- 링크 주소는 변경하지 않았다. 이번 최종 검사는 HTML 내부 연결 검사이며, 외부 사이트 접속 결과는 앞선 10월 3일 검토 기록을 참조한다.
- 업로드 파일: `noonting/seoulcalendar.html`. 서버에서도 상위 폴더의 `owmoosa-projects.css`와 `index.html` 상대 경로를 유지한다. 이 두 파일은 이번 수정 대상이 아니다.
- 로컬 브라우저 시각 검증과 서버 배포는 수행하지 않았다.
